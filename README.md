# GNC for a thrust-vector-controlled model rocket

6-DOF simulation and flight software for a ~0.83 kg, 60 mm model rocket with a single gimballed
motor (representative G-class curve, 131 N·s, 2.4 s burn). Built twice from the same equations:

| | where | how it runs |
|---|---|---|
| MATLAB script loop | `matlab/run_sim_matlab.m` | fixed-step RK4, 1 ms plant, 100 Hz flight computer |
| Simulink model | `matlab/rocket_tvc.slx` | generated by `build_simulink_model.m`, solved with `ode4` at 1 ms |
| Python package | `python/rocket_tvc/` | NumPy port, same RK4 and timing |

The three agree to ~1e-12 on every state when fed the same noise (checked, see below).

## What is modelled

- **Plant**: quaternion rigid body, thrust with gimbal + static misalignment, burn-dependent mass / CG / inertia,
  linear normal-force aero at the CP, drag, pitch/yaw/roll damping, exponential atmosphere, steady wind + 1-cos gust, pad hold.
- **Actuator**: first-order servo (10 Hz), ±7° travel, 250°/s rate limit.
- **Sensors**: 100 Hz gyro + accelerometer with turn-on bias, white noise, gyro saturation.
- **Timing**: command computed at *t_k* reaches the servo at *t_k + Ts* (one-sample delay), then held.
- **Flight computer** (`flight_computer.m` / `gnc.py`): pad calibration (gyro bias, levelling) → lift-off detection from
  the accelerometer → strapdown attitude → tilt-error PID in angular-acceleration units → converted to a gimbal angle with
  `τ = −l·T·δ`, thrust estimated from the accelerometer so the gain follows the thrust curve → burn-out detection, gimbal centred.
- **Guidance**: vertical, smooth 8° pitch-over, smooth return to vertical before burn-out.
- **Deliberately marginal airframe**: CP at 0.475 m from the nose, CG moves 0.487 → 0.460 m, so it is slightly
  *unstable* at lift-off and slightly stable at burn-out.


## Results (nominal case, seed 1)

- Apogee 600 m, burn-out speed 123 m/s. Max gimbal use 1.2° of the 7° available.
- Boost tilt error: max 3.9°, rms 2.0° (starts with a 2° pad tilt; the rest is tracking lag on the 24°/s pitch-over).
- Simulink vs script vs Python: max state difference 2e-13 (Simulink), 6e-13 (Python).
- Monte Carlo, 30 random cases (wind to 6 m/s, gust to 10 m/s, ±5 % thrust, 0.4° misalignment, 1.5 mm CG offset, 0–3° pad tilt):
  closed loop 30/30 within 15°, worst tilt error 4.6°; gimbal locked 0/30 (mean apogee 49–112 m: it tumbles).
- Where the design breaks (`results/sweeps_matlab.png`, one parameter degraded at a time):

| Degraded | Still fine | Fails |
|---|---|---|
| Flight-computer period | 20 ms | 40 ms and slower |
| Servo bandwidth | 2 Hz (tilt error 6°) | 1 Hz |
| Gimbal travel | 1° (5 % of boost saturated) | 0.5° |
| Gyro noise | 50× nominal (tilt error 17°) | 100× |
| Servo rate limit | even 12°/s | — |
| Gust amplitude | 20 m/s | — |

So for this vehicle timing and actuator bandwidth set the limit; the rate limit and gusts barely matter because
the commanded gimbal motion is small and slow. Most of the gimbal travel is spare authority.

## Known limitations 

- **Attitude estimate is open-loop strapdown after levelling.** In powered flight the accelerometer reads thrust,
  not gravity, so it cannot correct tilt. Error stays <0.6° during boost but drifts to ~1.6° by t = 13 s (no aiding).
  Natural next step: a MEKF with baro/GPS aiding.
- **Roll is not controlled** (single nozzle cannot). Small fins provide roll damping (`Clp`); roll rate still peaks at ~57°/s (about 0.12 turn during the burn),
  while pitch/yaw rates peak at 35°/s and 17°/s. (`max_rate_dps` in the metrics reports pitch/yaw only.)
- Motor curve, aerodynamic coefficients, CP and inertia are *representative estimates*, not measured values for a
  specific rocket. Replace them in `rocket_params.m` / `params.py` before trusting numbers for a real vehicle.
- No jet damping, launch rail, Earth rotation, servo backlash or sensor misalignment; the IMU sits at the CG.
- Simulink uses MATLAB Function blocks that call the same `.m` files as the script, so the model is a faithful
  harness around them rather than a native-block rebuild.
